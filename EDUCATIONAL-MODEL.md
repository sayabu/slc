# Educational financial model — accepted direction, October 13, 2026

## Purpose

This is a free communication tool for awareness and education. The customer is not buying a report. Its estimates should illustrate possible financial scale using a sound, transparent methodology rather than claim precision. Good literature and reasonable assumptions support scenarios when site data is limited. No new spending does not mean no potential loss of useful staff time. Results are a range of assumption-based possibilities, not a verdict. The primary next step is an in-building cellular signal survey.

Start at zero usable cellular coverage throughout every building entered for the campus. This is hypothetical unless measured. Customers can enter the extent of coverage they may currently have, separately for each building. Do not interpret the default as a finding about the property.

## Accepted choices (all A)

1. Dollars represent possible wage value of lost staff time, not measured cash expense or guaranteed savings.
2. Prefer annual FTE, then headcount, then matching reviewed facility data, then an appropriate labeled size-based estimate. No invented shift multiplier.
3. Staffing scope must match the building/campus. Never repeat a campus count for multiple buildings. Institution-wide imports need a defensible allocation method before use.
4. Match published wages to ownership and geography; customer payroll averages may be an optional future override.
5. Unknown coverage is a labeled scenario, not a confirmed zero-coverage measurement.
6. Proportional floor-area exposure is the simple disclosed assumption. An optional staff-location adjustment is a future extension, not a current input.
7. Show direct time first; the research-informed 1% cognitive allowance is an optional combined comparison with an overlap warning.
8. AI research should provide sourced suggestions the user can accept or correct. This integration is not implemented yet.
9. Keep indirect effects Not Quantified without facility-specific evidence and an approved attribution method.
10. Encourage a signal survey of in-building coverage, then update the model with measured coverage.

## Implemented presentation

Educational presentation 2.1 selects direct-only time by default and allows the additive cognitive comparison. The underlying engine still returns the original version 2.0 direct and cognitive components and combined API fields. The shared presentation function selects the displayed hours/dollars without rounding intermediate values. API consumers must not interpret the legacy combined baseline field as the educational default.

The displayed annual comparison is direct-only versus the optional combined allowance. It is not a validated lower/upper bound, a guaranteed minimum, or a statistical confidence interval. No newly invented lower-time coefficient was introduced. Other lower/reference/higher lost-time assumptions require explicit documented approval before implementation.

The equation journey traces workforce, uncovered share, annual lost-time assumption and hourly wages. Result diagrams use the actual calculated building values and BLS source link. The standalone /model explainer uses an explicitly illustrative 1,000-FTE, $40/hour example and an interactive coverage slider. No example wages enter production calculation data.

Evidence quality is described in words, separately from mathematical correctness. User inputs are not automatically verified. Published wages are averages. Lost-time assumptions are not site-validated. Do not invent a confidence percentage from an AI's self-assessment.

## Remaining research integration

Implement an authenticated/server-side research service with a chosen provider and credentials, source allowlists, retrieved source passages, units, reporting dates, provider/address matching, scope checks and explicit user acceptance. Prefer structured government APIs for factual numbers. The model may explain/extract source material; ordinary code validates values and performs arithmetic. Missing/conflicting data must remain visible. Website text cannot instruct the research system to override policy. Track accuracy on human-checked examples before release. Do not infer RF coverage or alter model coefficients from unsourced AI output.

No live CMS/CCD/IPEDS/LODES integration has been added. Ownership is selected in the form; omitted ownership in legacy API requests retains the configured default. Government office density requires confirmation of administrative use when actual staff counts/reviewed facility FTE are absent.
